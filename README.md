# 表格合并清洗器 v1.0

> 把十几个格式不一的 Excel / CSV，一键合成一张能直接用的干净表格。
> 双击运行，不需要装 Python。

---

## 它解决什么问题

月底对账、门店汇总、多个部门交报表的时候，最耗时的从来不是"算"，而是：

- 十几个文件，列名不一样（有的叫"客户名称"，有的叫"客户"）
- 每个格子前后带空格，看着一样其实匹配不上
- 表头中间夹着空行、空列
- 同一个订单在两个月里重复出现
- CSV 打开是乱码（GBK / UTF-8 编码不一致）

人工做一遍两三个小时，还容易漏。这个工具做一遍几十秒。

**处理后的效果**：所有文件纵向合并成一张宽表，缺的列自动留空，自动加上"来源文件/来源Sheet"两列方便追溯，空格清掉，空行空列删掉，可选去重。
