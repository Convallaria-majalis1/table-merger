# 表格合并清洗器 v1.0

> 把十几个格式不一的 Excel / CSV，一键合成一张能直接用的干净表格。
> 双击运行，不需要装 Python。

---

## 一、它解决什么问题

月底对账、门店汇总、多个部门交报表的时候，最耗时的从来不是"算"，而是：

- 十几个文件，列名不一样（有的叫"客户名称"，有的叫"客户"）
- 每个格子前后带空格，看着一样其实匹配不上
- 表头中间夹着空行、空列
- 同一个订单在两个月里重复出现
- CSV 打开是乱码（GBK / UTF-8 编码不一致）

人工做一遍两三个小时，还容易漏。这个工具做一遍几十秒。

**处理后的效果**：所有文件纵向合并成一张宽表，缺的列自动留空，自动加上"来源文件/来源Sheet"两列方便追溯，空格清掉，空行空列删掉，可选去重。

## 二、在自己电脑上跑通（约 15 分钟）

### 1. 确认 Python 版本

打开命令行（Win + R 输入 `cmd`），执行：

```bat
python -V
```

看到 `Python 3.9.x` 及以上就行。如果是 3.7/3.8，建议去 python.org 装一个 3.11 或 3.12，**不要卸载旧的**——PyCharm 里可以给不同项目指定不同解释器。

你自己电脑上已经装了 Python，这一步大概率直接通过。

### 2. 装依赖

在项目目录下执行：

```bat
python -m pip install -r requirements.txt
```

三个包：`pandas`（处理表格）、`openpyxl`（读写 xlsx）、`xlrd`（读老式 xls）。

> 用 PyCharm 的话：打开项目后右下角会提示"未安装依赖"，点一下就能装；也可以在 Terminal 面板里执行上面这条命令。

### 3. 运行

```bat
python main.py
```

会弹出一个窗口。**也可以直接双击 `运行.bat`**，它会自动装依赖并打开界面。

结果默认存在程序目录下的 `合并结果.xlsx`（在界面里点"另存为…"可以改位置）。用 `示例数据/` 里的三个文件试一遍：

- 添加 `1月订单.xlsx`、`2月订单.csv`、`3月订单.xlsx`
- 勾上"读取全部 Sheet"
- 勾上"去掉重复行"
- 点"开始合并"

正常结果：13 行原始数据 → 11 行干净数据（去掉 1 个重复、1 个空行），7 列。

### 4. 只用命令行也行

```bat
python core.py 示例数据\1月订单.xlsx 示例数据\2月订单.csv -o 结果.xlsx --dedupe
```

## 三、打包成 exe（约 5 分钟）

双击 `build.bat`，等它跑完。产物在：

```
dist\TableMerger.exe
```

这个 exe 可以直接发给客户，对方电脑不需要装 Python。

**注意两点：**

1. 第一次双击启动会慢（10 秒左右），因为要把 pandas 解压出来，属于正常现象，提前跟客户说一句。
2. 如果客户电脑的杀毒软件误报（PyInstaller 打包的通病），改用文件夹模式：把 `build.bat` 里 `--onefile` 改成 `--onedir`，打包成一个文件夹，压缩成 zip 发过去，误报会少很多。

## 四、交付给客户时的标准动作

1. 发 exe + 一份 `使用说明.txt`（就把本文件"它解决什么问题"那一段改一下发过去）
2. 发一段 30 秒屏录，演示"选文件 → 点开始 → 出结果"
3. 交付话术：**"以后每个月把文件丢进去点一下就行，不用再手工拼表。"**
4. 主动追一句：**"要不要我帮你设成每周自动跑、结果自动发到你邮箱？"**——这是包月维护的入口。

## 五、能力边界（很重要，别过度承诺）

| 能做 | 不做 |
|---|---|
| Excel / CSV 纵向合并 | 跨表按字段做关联（VLOOKUP 那种匹配） |
| 列名不一致时自动取并集 | 复杂的多级表头识别 |
| 清理空格、空行、空列 | 自动纠正错误的业务数据（比如金额写反） |
| 按整行去重 | 图片、图表、公式的保留 |
| 长数字列（订单号等）按文本存储 | 加密文件、需要密码的表格 |

客户问的时候，把"不做"这一列说清楚，后面就不会扯皮。

## 六、常见报错对照

| 现象 | 原因 | 解决 |
|---|---|---|
| `ModuleNotFoundError: pandas` | 依赖没装 | `python -m pip install -r requirements.txt` |
| 双击 exe 闪一下就没了 | 有异常但窗口关了 | 用 cmd 进到 exe 目录，命令行运行看报错 |
| `UnicodeDecodeError` | CSV 编码特殊 | 已在代码里自动尝试 utf-8-sig / gb18030 / utf-8，仍失败就把文件发我看 |
| `xlrd` 相关报错 | 读 .xls 缺依赖 | `python -m pip install xlrd` |
| 打包后启动很慢 | onefile 模式解压 | 属正常，或改 `--onedir` |

├── main.py              # 图形界面（tkinter）
